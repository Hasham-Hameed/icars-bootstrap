# Icars — Bootstrap Showcase

A responsive premium automotive website built with Bootstrap 5.

🔗 Live Site: https://hasham-hameed.github.io/icars-bootstrap/

---

## What's Inside

- Responsive navbar with dropdown and search
- Full-screen image carousel with captions
- Brand cards with circular images (Porsche, Toyota, Nissan)
- Featurette sections with alternating layouts
- Custom dark luxury theme with gold accents

## Built With

- HTML5
- CSS3
- Bootstrap 5.3.8
- Google Fonts
